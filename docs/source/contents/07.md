## Installation

- [Option 1] To install the latest release from PyPI:

```bash
$ pip install causallift
```

- [Option 2] To install the latest pre-release from GitHub:

```bash
$ pip install git+https://github.com/Minyus/causallift.git
```

- [Option 3] To install for local development and keep using your working tree:

```bash
$ git clone https://github.com/Minyus/causallift.git
$ cd causallift
$ pip install -r requirements.txt
$ pip install -r requirements_dev.txt
$ pip install -e .
```

### Runtime dependencies:

Versions are intentionally flexible here, with only `pipelinex>=0.8.0` constrained.

- numpy
- pandas
- scikit-learn
- easydict
- kedro
- kedro-datasets
- pipelinex>=0.8.0

### Optional:

- matplotlib
- xgboost
- scikit-optimize

### Optional for visualization of the pipeline:
